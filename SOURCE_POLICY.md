# Official Distribution and Third-Party Source Policy

## Protocol-only official scope

The Origo Source Protocol project publishes a neutral HTTP protocol,
schemas, conformance tools, and original reference fixtures. It does not
operate, distribute, recommend, endorse, or certify any third-party book source
and does not provide an official source feed.

The `registry/` directory is retained only as a reference data format and
tooling example for independent communities that choose to operate their own
registries. This repository does not accept source-listing submissions, and the
official Origo X app does not consume `registry/generated/registry.json`.

## Responsibility for source content

ORSP conformance is a technical compatibility statement. It does not prove
that a source is lawful, safe, accurate, trustworthy, or authorized to
distribute its content. Source operators are responsible for the services and
content they provide. Users and reader operators decide independently which
source addresses to add or distribute.

ORSP must not be used to bypass access controls, authentication, paywalls,
digital rights management, provider terms, or applicable law.

## Rights reports

This project cannot remove content from independently operated sources. A
rights report about source content should be sent to that source operator or
its hosting provider.

If a file, example, link, or other location controlled by this repository
unexpectedly contains infringing material, open a GitHub issue identifying the
exact repository path or URL, the claimed right, the requested action, and a
way to contact the reporter. Use a private GitHub Security Advisory if the
report contains sensitive personal or security information.

Maintainers will address material the project actually controls. Compatibility
tests, schemas, and reference registry tooling are not legal certification or
endorsement. Limitations of liability apply only to the extent permitted by
applicable law.
